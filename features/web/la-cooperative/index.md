# La coopérative — page de présentation

Page `/la-cooperative/` : l'ADN de La Coop des Hauts-Prés, sans le détail juridique.

- Contenu rédigé dans `web/src/content/cooperative.ts`, d'après les statuts. Les statuts eux-mêmes ne sont ni versionnés ni téléchargeables sur le site.
- Seuls les principes durables sont publiés : raison d'être, objectifs, valeurs, catégories de sociétaires, collèges de vote, gouvernance, lucrativité limitée.
- Volontairement absents (susceptibles d'évoluer) : montants, délais, quorums, majorités détaillées, durées de mandat, nombre de membres du Directoire, noms de personnes, numéros d'articles.
