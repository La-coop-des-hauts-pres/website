# Politique de sécurité

Merci de nous aider à protéger la Coop, ses sociétaires et les personnes qui visitent le site.

## Signaler une vulnérabilité

Écrire à **thibault@kolombo.fr**, avec pour objet « Sécurité — Hauts-Prés ».

**Ne pas ouvrir d'issue publique** pour un problème de sécurité ni pour une fuite de
données personnelles : les issues sont visibles de toutes et tous.

Merci d'indiquer :

- ce que vous avez observé et où (page, route de l'API, fichier) ;
- les étapes pour le reproduire ;
- l'impact que vous imaginez ;
- comment vous répondre.

N'incluez jamais de données personnelles réelles dans le signalement. Si vous en avez
croisé par accident, ne les copiez pas, ne les diffusez pas et dites-nous simplement où
elles se trouvent.

## Ce que nous faisons

- Accusé de réception sous 5 jours ouvrés.
- Point d'avancement régulier jusqu'à la correction.
- Correction aussi vite que possible, puis remerciement public si vous le souhaitez.
- En cas de fuite de données personnelles, information des personnes concernées et de la
  CNIL dans les délais du RGPD (72 heures).

## Ce que nous demandons

- Tester uniquement avec vos propres données, sans accéder aux données d'autrui.
- Ne pas dégrader le service (pas de test de charge, pas de déni de service).
- Nous laisser un délai raisonnable pour corriger avant toute publication.

Nous n'engagerons pas de poursuites contre une personne qui suit ces règles de bonne foi.
Il n'y a pas de programme de récompense financière.

## Versions concernées

Seule la branche `main` est maintenue.
